Robotics software needs to be both fast and safe, and the robotics community is increasingly looking at Rust as a language that can deliver both. Our lab led the Rust for Robotics workshop at ICRA 2025 and led the follow-up workshop Why Rust for Robotics at IROS 2026 in Pittsburgh.

This student project explores Rust for aerial robotics software in the lab. Students will prototype robotics components in Rust, compare them with their existing C++ counterparts, and help the lab evaluate where Rust fits best in a real flight software stack. Strong contributions can feed into the lab's workshop activities and open-source presence.

## Desired Skills

Students are not expected to have experience in every area, but familiarity with one or more of the following is desirable.

• Programming in Rust, or strong C++ skills and an interest in learning Rust

• ROS 2 or other robotics middleware

• An interest in flight software, embedded systems, or developer tooling
